PYTHON

O que é Python?

Python é uma linguagem de programação criada por Guido van Rossum e lançada em
1991. Ela é conhecida por ter uma sintaxe simples e fácil de ler, o que a torna
uma ótima escolha para quem está começando a programar.

Video introdutorio sobre python

Para que serve?

    Python é muito versátil e pode ser usada em várias áreas:

    1. Sites e sistemas web, com ferramentas como Django e Flask
    2. Ciência de dados, para analisar e organizar informações
    3. Inteligência artificial, para criar programas que aprendem sozinhos
    4. Automação, para fazer o computador executar tarefas repetitivas
    5. Jogos, com bibliotecas como o Pygame

    Por que aprender Python?

    1. Fácil de ler: o código se parece com o inglês.
    2. Iniciante-friendly: você aprende os conceitos sem se perder em regras complicadas.
    3. Comunidade gigante: há muito material, tutoriais e ajuda disponível.
    4. Muito usada no mercado: empresas do mundo todo usam Python.
    5. Gratuita: qualquer pessoa pode baixar e usar.

    Código de Exemplo

    O clássico "Olá, mundo!" em Python tem só uma linha:

    print("Olá, mundo!")

    Conceitos básicos

    1. Variáveis

      2. Servem para guardar informações.

      nome = "Maria" idade = 18

    2. Condições

      3. Permitem que o programa tome decisões.

      if idade >= 18: print("Maior de idade") else: print("Menor de idade")

    3. Repetições

      4. Fazem o programa repetir uma ação.

      for numero in range(5): print(numero)

    4. Funções

      5. São blocos de código que você pode reutilizar.

      def saudacao(nome): print("Olá,", nome) saudacao("Carlos")
